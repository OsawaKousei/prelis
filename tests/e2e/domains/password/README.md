# パスワード生成の E2E

macOS の既存アプリを UI から操作し、生成結果の性質と実際のクリップボードを確認します。

1. 起動直後は未生成でコピーできないことを確認する。
2. 既定の16文字を生成し、大文字・小文字・数字・記号をそれぞれ含み、許可された文字だけであることを確認する。
3. コピーを押し、成功表示とクリップボードの文字列が生成結果と完全一致することを確認する。
4. 「間違えやすい文字を除く」を有効にする。既存の結果が消えてコピーが無効になり、次の16文字は `I O l 0 1` を含まないことを確認する。
5. 大文字・小文字・記号を外し、数字だけで4・8・12・16文字をそれぞれ生成する。長さが一致し、除外設定に従って `2`〜`9` だけであることを確認する。
6. 数字も外し、文字種が0個のときに生成・コピーが無効になり、案内が表示されることを確認する。

乱数の結果を固定せず、選択条件を満たすかを検証します。クリップボードの元のデータはすべての形式をメモリ内に一時退避し、テスト終了時に復元します。元のデータをログやファイルへ保存しません。実行中に外部から別の内容がコピーされた場合は、その新しい内容を上書きせず失敗として報告します。生成条件はアプリ内で永続化されないため、テスト終了時のアプリ終了でリセットされます。

```sh
npm run test:e2e:macos -- --app /absolute/path/to/PrelisDesktop.app --domain password --record
```

準備と結果の確認方法は [テスト運用](../../../../docs/development/testing.md)を参照してください。
