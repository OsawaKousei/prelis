# タイマーの音声 E2E

macOS の既存アプリを UI から操作します。音声は ScreenCaptureKit でアプリから実際に取得した録音を解析し、UI の表示だけで成功とは扱いません。

1. アプリを起動し Timer の設定を開く。元の音声選択を読み取り、一意に復元可能なことを確認する。
2. `fixtures/timer/alert.wav` の一時コピーをファイル選択パネルから追加する。一時コピーの名前は実行ごとに変える。
3. 試聴を押し、660 Hz → 880 Hz の2音を録音で確認する。
4. 1分に設定して開始し、実時間で完了を待つ。開始要求から58〜75秒の範囲に2音が録音されることを確認する。
5. リセット後の UI が停止状態に戻り、録音が無音になることを確認する。
6. 追加したテスト音声だけを削除し、元の音声選択を復元してアプリを終了する。

合成 WAV は16 kHz・モノラル・PCM16・約0.8秒です。既存の審査資料用に作成した合成音声のコピーで、第三者の音楽は含みません。`audio-analysis.py` は動画から復号した同形式の PCM を50 msごとに解析し、振幅と周波数の両方を判定します。無音、別の周波数、1音だけ、早すぎる終了音、リセット後も続く音を拒否する回帰テストがあります。

このテストは出力ストリームの検証です。物理スピーカーやヘッドホンから実際に聞こえることは別途確認してください。時間短縮用のアプリ内モードや、提出対象へのコード追加は使用しません。OS のファイル選択パネルはメインウィンドウの動画には含みません。

```sh
npm run test:e2e:macos -- --app /absolute/path/to/PrelisDesktop.app --domain timer --record
```

準備・生成物・TestFlight の扱いは [テスト運用](../../../../docs/development/testing.md)を参照してください。
