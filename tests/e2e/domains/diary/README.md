# 日記の E2E テスト

## 共通の期待結果

1. 保存されていない日付を UI から選ぶ。
2. 固定の文章を入力し、保存完了を確認する。
3. アプリのプロセスを終了する。
4. 同じアプリを再起動し、同じ日付を選ぶ。
5. 入力文章と完全一致することを確認する。
6. テスト入力を消して保存し、アプリを終了する。

## macOS

- Tauri / WebKit の実際のアクセシビリティ要素を使用する。本文は `TextView`、`aria-pressed` を持つカレンダーの日付は `CheckBox` として取得する。
- 起動時点の翌日から14日先までを調べ、最初の空の日付を使用する。空の日付がなければ失敗として終了する。
- 入力値を取得できない場合は、空と解釈せず失敗とする。
- 後片付けでは、テスト文章または空文字列であることを確認する。別の内容なら消去しない。
- 後片付け後も空の日記ファイルは残り得る。テストには専用の Mac ユーザーを推奨する。
- 強制終了・クラッシュ・通信断などでは後片付けが完了しない場合がある。結果の `Test date:` アクティビティと固定入力を確認し、手動で復旧する。
