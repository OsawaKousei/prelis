# ウェブ版の開発・配信

ウェブ版は `apps/web` の Vite CSR アプリです。ルートの npm workspace と lockfile を使用します。初回はルートで `npm ci` を実行します。

```sh
npm run dev:web
npm test -w apps/web
npm run build:web
```

開発サーバーは Vite の表示する URL から開きます。ビルド成果物は `apps/web/dist/` に生成され、静的ホスティングへ配置できます。配信時は HTTPS を使用してください。パスワードのコピーなど一部のブラウザー API が安全な接続を要します。公開先や配信設定は、このリポジトリにはまだ定義していません。

日記と終了音は同一オリジンの IndexedDB に保存します。デスクトップ版・Android 版との同期や移行機能はなく、ブラウザーのサイトデータを削除すると失われます。タイマーの進行状態はタブ内のみで、再読込・タブを閉じるとリセットされます。画面非表示中に時間になった場合は、画面へ戻った際に完了を表示し、終了音は再生しません。表示中でも音声再生が拒否された場合はエラーを表示します。

変更時は型チェック・ビルド・仕様テストに加え、ブラウザーで Diary の保存と再読込、Timer の操作と音声の追加・選択・削除、Password の生成とコピーを確認します。画面幅を変えてカレンダーと設定欄も確認します。
