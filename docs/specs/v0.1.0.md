# v0.1.0 現行仕様

日記・タイマー・パスワード生成の共通仕様をまとめる。プラットフォームごとの細かな違いは省略する。

## 共通

- アプリ内で日記・タイマー・パスワード生成を切り替えて利用する。
- 日記と追加した終了音・音声の選択設定は端末・ブラウザー内に保存し、次回起動時も利用できる。
- アカウント認証、クラウド保存、端末間の同期・データ移行機能は提供しない。
- 読み込み・保存・生成・コピー・音声再生などに失敗した場合は、エラーを表示する。

## 日記（Diary）

- 日付ごとにプレーンテキストを編集し、保存ボタンで保存する。再度その日付を開くと保存済みの内容を読み込む。
- 初期表示は今日とし、前日・翌日・今日への移動とカレンダーによる日付選択ができる。
- 本文の文字数と、未保存・保存中・保存済みなどの状態を表示する。
- 未保存の変更がある場合、別の日付や機能へ移動する前に破棄を確認する。キャンセルすると編集を続けられる。
- 保存中は本文編集と別の日付・機能への移動を抑止する。保存失敗時は入力内容を保持し、再試行できる。
- 読み込みに失敗した場合は再読み込みでき、既存データを上書きしない。

## タイマー（Timer）

- 1～180分の整数を設定する。初期値は25分とし、範囲外の値では開始できない。
- 開始・一時停止・再開・リセットができ、残り時間と進捗を表示する。
- アプリ内で別の機能へ移動しても計時を維持する。アプリの終了・再読み込み後に計時状態は引き継がない。
- 実行中と完了後は設定時間・終了音を変更できない。リセットすると音声を停止し、設定時間に戻す。
- 終了音として10 MB以下の MP3・WAV を追加でき、選択・試聴・削除と「音声なし」の選択ができる。
- 残り時間が0になると完了を表示し、選択した終了音を繰り返し再生する。「音声なし」の場合は再生しない。
- バックグラウンド通知や、バックグラウンドでの正確な時刻の終了音再生は保証しない。

## パスワード生成（Password）

- 使用する文字種を英大文字・英小文字・数字・記号から選択する。初期状態はすべて選択する。
- 使用可能な記号は `!@#$%^&*_-+=?` とする。
- 文字数は4・8・12・16文字から選択し、初期値は16文字とする。
- 選択した各文字種を最低1文字含むパスワードを、暗号学的乱数で生成する。
- 文字種が未選択の場合は生成できない。
- 生成結果を表示し、クリップボードへコピーできる。文字種・文字数を変更すると以前の結果を消去する。
