# Diary・Timer・Password

## 状態

既存デスクトップ実装を基準に、Android に3機能を反映。デスクトップで実装済みの機能について、2026-10-11 にフロントエンドビルドを確認。Android は同日に JS バンドル、debug APK ビルド、API 37 エミュレーター上での起動を確認した。Diary の入力・保存、Timer の開始と残り時間更新、WAV の追加・試聴・削除、Password の生成を操作確認した。クリップボードへのコピーと実時間でのタイマー完了・終了音の反復再生は端末上では未確認（完了時の再生呼び出しは Jest で確認）。

## 共通の機能と受け入れ条件

### Diary

- 日付ごとにプレーンテキストの日記を端末内に保存し、再度その日付を開くと同じ内容を読み込める。
- 前日・翌日・今日・カレンダーから日付を選べる。
- 未保存の変更があるとき、別の日付やアプリへの移動前に破棄を確認する。保存中は移動できない。
- 保存や読み込みに失敗した場合、エラーを表示する。保存失敗時は入力を保持する。
- デスクトップと Android の日記データは端末ごとに独立する。同期機能はない。

### Timer

- 1～180分の整数を設定し、開始、一時停止、再開、リセットを行える。
- アプリ内で別画面へ移動しても残り時間を維持する。Prelis のプロセス終了時にはリセットする。
- MP3 / WAV（10 MB 以下）の終了音を端末に追加し、選択、試聴、削除できる。音声なしも選べる。
- 残り時間が0になると選択中の音声を繰り返し再生し、リセットで止める。
- Android でアプリがバックグラウンドにあるとき、JavaScript の実行停止により完了処理は復帰時に行われる場合がある。バックグラウンド通知・正確な時刻での再生は現仕様に含まない。

### Password

- 大文字、小文字、数字、記号から文字種を選び、4・8・12・16文字のパスワードを生成する。
- 選択した各文字種を最低1文字含める。乱数は OS の暗号学的乱数を使用する。
- 結果をコピーできる。条件変更時は以前の結果を消す。文字種が0件なら生成できない。

## UI と操作

デスクトップはサイドバーで切り替える。Android はホームと下部タブで切り替え、Diary は縦スクロール内に編集欄とカレンダーを置く。Timer と Password も縦スクロールで操作する。Android の戻るボタンはホームへ戻る操作とする。

## 確認方法

- Diary: 今日と別の日付へ保存し、再表示、破棄確認、保存失敗時の入力保持を確認する。
- Timer: 短い時間で開始・一時停止・再開・完了・リセット、画面切り替え、音声の追加・試聴・選択・削除を確認する。
- Password: 各文字種と文字数を変えて生成、コピー、条件変更時の消去を確認する。
