# 機能仕様書の索引

現在の製品機能: [Diary・Timer・Password](desktop-apps.md)。
挨拶画面は開発環境を確認するサンプルであり、製品仕様として扱いません。

## 追加方法

仕様が決まった機能ごとに、このディレクトリへ `<機能名>.md` を追加し、この索引からリンクします。
ファイル名には短い英小文字とハイフンを使用します。
1つの機能の共通仕様と、各アプリの UI・操作方法の差分を同じ文書で管理します。
[基本原則](../../AGENTS.md)に従い、提供機能と機能としての受け入れ条件は共通にします。
デスクトップでの確認後にモバイルへ反映するため、実装時期の差を恒久的な機能差として扱いません。

仕様書には次の内容を含めます。

- 目的と対象範囲。
- 状態（検討中・確定など）と未決定事項。
- デスクトップの実装・確認状況、モバイルへの反映・確認状況、反映待ちの内容。
- 共通の動作、データ、入力・出力、エラー時の動作。
- 各アプリで個別に開発する画面・操作と、モバイルの特徴に合わせた差分。
- 共通機能の受け入れ条件、各アプリの UI・操作の確認方法。
- 関連する仕様や実装へのリンク。

未決定事項は未決定と明示します。セットアップやビルドのコマンドは仕様書へ転記せず、
[開発手順](../development/workflow.md)を参照してください。
