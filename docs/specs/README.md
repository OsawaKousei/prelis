# 機能仕様書の索引

製品機能の仕様書はまだありません。
現在の挨拶画面は共有ロジックと開発環境を確認するサンプルであり、製品仕様として扱いません。

## 追加方法

仕様が決まった機能ごとに、このディレクトリへ `<機能名>.md` を追加し、この索引からリンクします。
ファイル名には短い英小文字とハイフンを使用します。
1つの機能の共通動作とプラットフォーム差分を同じ文書で管理します。

仕様書には次の内容を含めます。

- 目的と対象範囲。
- 状態（検討中・確定など）と未決定事項。
- 共通の動作、データ、入力・出力、エラー時の動作。
- 画面・操作と、デスクトップ・Android などの差分。
- 受け入れ条件と確認方法。
- 関連する仕様や実装へのリンク。

未決定事項は未決定と明示します。セットアップやビルドのコマンドは仕様書へ転記せず、
[開発手順](../development/workflow.md)を参照してください。
