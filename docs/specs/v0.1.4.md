# v0.1.4 追加・変更仕様

変更のない機能は [v0.1.3](v0.1.3.md) と同書が参照する仕様を引き継ぐ。

## 対象とバージョン

- デスクトップ（Linux・Windows・macOS）とモバイル（Android・iOS）を `0.1.4` に更新する。ウェブ版は対象外。
- 各アプリの npm パッケージ・lockfile・画面表示・ネイティブ設定を揃える。モバイルのビルド番号は Android・iOS ともに `3` とする。

## プライバシーポリシー

- URL は `https://prelis.prj.kupac.co.jp/privacy` とする。
- デスクトップは、全機能から利用できるサイドバー下部に「プライバシーポリシー」リンクを表示する。既存の Tauri Opener で既定の外部ブラウザーを開く。
- モバイルはホーム画面に同じラベルのリンクを表示する。既存の Expo Linking で既定の外部ブラウザーを開く。タッチ領域の高さは44以上とする。
- 支援技術へリンクとして伝え、ブラウザー起動失敗時には画面上にエラーを表示する。デスクトップではキーボードのフォーカスを視認できるようにする。
- ポリシーの閲覧にはインターネット接続が必要。日記・タイマー・パスワード生成の処理と保存方法は変更しない。

## 検証と審査資料

- デスクトップの Vite では React・React DOM の解決先をデスクトップ側に統一する。モバイル用にルートへ配置された別バージョンを共有依存が取り込み、起動時に空画面となる問題を防ぐ。
- 今回は Linux のネイティブアプリで動作確認する。他のプラットフォームのビルド・実機確認は実施しない。
- iOS 審査メモと返信の英文テンプレートを `dist/app-store-ios/app-review-notes.txt` と `app-review-reply.txt` に保存する。
- 動画・実機テスト・提出ビルドなど未確定の値はプレースホルダーにし、実施済みと記載しない。再提出前に実際の結果で置換する。
