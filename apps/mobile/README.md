# Prelis Mobile

React Native のモバイルアプリです。
画面の切り替えは `App.tsx`、各機能の UI は `src/`、Android のネイティブ処理は `android/` に配置しています。
共通処理は `@prelis/core`、デスクトップと共通の PNG アイコンは `@prelis/icons` を利用します。iOS 対応は保留中です。
