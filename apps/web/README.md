# Prelis Web

日記・タイマー・パスワード生成を提供する React/Vite の CSR 版です。共通ロジックとアイコンは `@prelis/core`・`@prelis/icons` を使用します。

開発・検証・配信方法は [ウェブ版の開発手順](../../docs/development/web.md)、機能の振る舞いは [仕様書](../../docs/specs/desktop-apps.md) を参照してください。
配信用の AWS リソースと公開手順は [ウェブ版配信インフラ](../../infra/web-frontend/README.md) にあります。
